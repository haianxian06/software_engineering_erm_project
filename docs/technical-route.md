# 技术路线

## 项目定位

项目名称：基于 Web 与关系型数据库的作业收集管理系统。

本版本面向期末作业演示，保留最核心的业务闭环：管理员发布作业，学生提交文件，系统自动重命名归档，管理员查看提交统计和未交名单。

## 功能范围

保留功能：

- 学生和老师注册。
- 老师创建班级，并按专业自动加入学生。
- 班级内学生可被设置为管理员。
- 管理员发布作业收集任务。
- 学生查看作业列表并上传文件。
- 后端保存提交记录和文件记录。
- 文件按“学号_姓名_作业名”重命名。
- 管理员查看每份作业的已交名单、未交名单和提交率。

暂不实现功能：

- 微信小程序端。
- 大文件断点续传。
- PDF 格式转换。
- 自动催交通知。
- 云端一键打包。
- 高并发和三万人规模支撑。

这些内容可作为答辩中的未来扩展方向。

## 技术选型

前端：

- Vue 3
- Vite
- Vue Router
- Pinia
- Axios
- Element Plus

后端：

- Spring Boot 3
- Spring Web
- Spring JDBC
- MySQL Connector/J

数据库：

- MySQL 8
- 使用 InnoDB 引擎
- 使用外键表达实体关系
- 按第四范式拆分多值属性，例如作业允许文件类型保存到 `assignment_file_type` 表，班级成员关系保存到 `class_member` 表

部署：

- Windows 本地开发
- Linux 云服务器部署
- Nginx 部署前端静态文件
- Spring Boot 运行后端接口
- MySQL 保存业务数据
- 后续可接入阿里云 OSS 保存作业文件

## 系统架构

```text
浏览器网页端
    |
    | HTTP / JSON / 文件上传
    v
Spring Boot 后端服务
    |
    +-- MySQL：保存用户、班级、班级成员、作业、文件类型、提交、文件记录
    |
    +-- 本地 uploads 目录：开发阶段保存文件
```

上线到阿里云后的目标架构：

```text
浏览器
    |
    v
Nginx 前端静态页面
    |
    v
Spring Boot API
    |
    +-- MySQL
    |
    +-- 阿里云 OSS
```
